# Default Avatar Images

This directory contains the 9 default avatars that are randomly assigned to new students when they first log in.

## Required Files

Place 9 avatar images in this directory with the following naming pattern:
- `avatar-1.png`
- `avatar-2.png`
- `avatar-3.png`
- `avatar-4.png`
- `avatar-5.png`
- `avatar-6.png`
- `avatar-7.png`
- `avatar-8.png`
- `avatar-9.png`

## Image Requirements
- Format: PNG (recommended) or JPG
- Size: Square images work best (e.g., 200x200px or 300x300px)
- Naming: Must follow the pattern `avatar-1.png`, `avatar-2.png`, etc.

## How It Works

When a student logs in for the first time:
1. The system checks if they have a selected avatar
2. If not, a random avatar from these 9 default avatars is automatically assigned
3. The avatar is saved to their profile in the database

These default avatars are free to use and don't require any XP to unlock.
